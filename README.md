### 🚀 What I'm building

**[Orbita](https://www.gabrielcaramuru.com.br)**: a multi-agent AI system that runs a one-person business.
A manager agent receives the owner's instructions by WhatsApp or Telegram and delegates to specialized agents (scheduling, sales, closing, legal/contracts, financial follow-up), from first contact to payment.
Built for solo professionals: doctors, dentists, psychologists, therapists and coaches.
